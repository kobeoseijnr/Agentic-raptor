# RAPTOR Repository

Two separated projects:

- **[RAPTOR_Legacy/](RAPTOR_Legacy/)** — the original `anglog` RAPTOR project (RAG-DPO
  Novelty Implementation): RAG memory, DPO reranking, MB-SAC sizing, MCTS graph
  refinement, SPICE evidence, experiments, results, datasets, and reports. Its own
  README is `RAPTOR_Legacy/README.md`. Run its commands from inside `RAPTOR_Legacy/`.
- **[Agentic_Raptor/](Agentic_Raptor/)** — Agentic RAPTOR: multimodal specification
  parsing, RAG-conditioned LLM topology generation, AlphaZero-inspired topology RL,
  graph-conditioned MB-SAC, real ngspice/PVT verification, pre-SPICE DPO ranking,
  cross-level credit assignment, and a LoRA fine-tuning pipeline. See
  `Agentic_Raptor/README.md`.

Agentic RAPTOR reaches legacy code strictly read-only through
`Agentic_Raptor/agentic_raptor/adapters/` (centralized path discovery pointing at
`RAPTOR_Legacy/`).

Separation artifacts: `REPOSITORY_SEPARATION_REPORT.md`,
`ORIGINAL_RAPTOR_FILE_INVENTORY.csv` / `.json` (generated by
`_separation_inventory.py`).
